Where it goes

Your own code

Your AI and the step that hands a conversation to a person are code you run. The file goes next to it, and two lines in that step, before the handover.

Which file, where

The file where your code decides to hand a conversation to a person: the function that puts it in a queue, opens a ticket for an agent, or transfers the call. Put the call to ask() right before that, and do the handover only when it does not return finish.

Python

Put stk.py next to that file. Set the environment variable STK_KEY to your test key; never write a key into the file.

import stk

def hand_over(conversation):            # your function, as it is today
    if stk.ask(conversation.intent, conversation.trigger, conversation_id=conversation.id) == "finish":   # trigger: a trigger that happened, or "unknown"
        return                          # your AI goes on with the conversation
    ...                                 # the handover, as your code does it today

def person_joined(conversation):        # where a person takes a conversation over
    stk.joined(conversation.id)         # a finish of it is taken off its day's bill

Node

Put stk.mjs next to that file. Set the environment variable STK_KEY to your test key; never write a key into the file.

import { ask, joined } from "./stk.mjs";

async function handOver(conversation) {   // your function, as it is today
  if (await ask(conversation.intent, conversation.trigger, { conversationId: conversation.id }) === "finish") return;   // trigger: a trigger that happened, or "unknown"   // your AI goes on
  // the handover, as your code does it today
}

async function personJoined(conversation) {   // where a person takes a conversation over
  await joined(conversation.id);              // a finish of it is taken off its day's bill
}

Where the rows are kept

By default, a folder stk-rows next to your code, one file a day (UTC). Nobody else has them: three ways to keep them.

1. On a disk that is backed up. Set the folder before your code starts; one folder for each server:

STK_ROWS_DIR=/var/lib/yourapp/stk-rows/$(hostname)

2. A second copy every night, of the day that ended (in the server's crontab, 00:30 UTC):

30 0 * * * cp /var/lib/yourapp/stk-rows/$(hostname)/$(date -u -d yesterday +\%F).jsonl /mnt/backup/stk-rows/

3. Where no file is kept (a serverless function): give each line to your own store. One that cannot be kept is told to STK as a person joining, and ask() returns escalate.

import json, stk

def keep(line):                      # each line, before ask() returns
    your_table.insert(json.dumps(line, ensure_ascii=False))

stk.ON_ROW = keep

Keep them as long as you may be asked about a conversation. STK's public keys are never deleted and every version of the rules stays published, so a row of any year can be checked.

What to pass

  • The intent: one of the 83 ids in The rules in full (each on its page from The rules). Map your own intent names to these on your side.
  • The trigger: one of the 6 triggers in The rules when it happened in the conversation (each says exactly what counts), or "unknown" when none did. The rules say escalate to every trigger.
  • Anything else you give ask() goes in your row, which stays with you; STK receives only its seal and its time.

Without an answer within 300 ms, or on any error, ask() returns escalate and your handover runs as it does today, unless a grant holds. Docs

A server of yours, for a platform that only calls an address

Put this next to stk.py on a server of yours that the platform can reach over HTTPS, and point the platform's step at it. Python 3.8 or later, nothing to install. What the platform sends it stays on that server.

import json, stk
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

class Ask(BaseHTTPRequestHandler):
    def do_POST(self):
        try:
            b = json.loads(self.rfile.read(int(self.headers.get("Content-Length", 0))))
            if self.path == "/joined":          # a person took the conversation over
                d = "told" if stk.joined(b.get("conversation_id")) else "not told"
            else:
                d = stk.ask(str(b["intent"]), str(b.get("trigger", "unknown")), conversation_id=b.get("conversation_id"))
        except Exception:
            d = "not told" if self.path == "/joined" else "escalate"
        out = json.dumps({"decision": d}).encode()
        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(out)))
        self.end_headers()
        self.wfile.write(out)

ThreadingHTTPServer(("0.0.0.0", 8787), Ask).serve_forever()

POST /stk (any path but /joined) with {"intent", "trigger", "conversation_id"} answers {"decision": "finish"} or "escalate". POST /joined with {"conversation_id"}, when a person takes the conversation over, tells STK. It answers on port 8787; put it behind HTTPS (a load balancer or a proxy) and, if the platform can send one, check a secret header before answering.
